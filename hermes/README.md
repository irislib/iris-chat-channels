# Iris Chat for Hermes

A native gateway channel with a dedicated persistent Iris identity, one approved
contact, text replies, and typing indicators. Uses your existing Hermes model.

Install `irislib/iris-chat-channels/hermes` with `hermes plugins install`, enable
`iris-chat-channel`, and choose **Iris Chat** in `hermes gateway setup`.

Read the complete [setup, boundaries, and recovery guide](https://github.com/irislib/iris-chat-channels#hermes).
Requires the Iris CLI and a supported Hermes host; installing the plugin does
not download either, create an account, or contact anyone.
